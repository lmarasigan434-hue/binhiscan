Ilagay dito ang tf.min.js para gumana ang scanner kahit WALANG internet:
1) Buksan: https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.17.0/dist/tf.min.js
2) I-save as "tf.min.js" sa folder na ito (app/src/main/assets/www/lib/)
Kapag wala ito, kukunin ng app ang TensorFlow.js sa internet (kailangan ng data/WiFi).
